# Triage Labels

스킬의 기본 역할을 아래 GitHub 라벨에 대응한다.

| 기본 역할 | GitHub 라벨 | 의미 |
| --- | --- | --- |
| needs-triage | needs-triage | 관리자의 검토와 분류가 필요함 |
| needs-info | needs-info | 제보자의 추가 정보를 기다림 |
| ready-for-agent | ready-for-agent | 명세가 충분하여 에이전트가 구현할 수 있음 |
| ready-for-human | ready-for-human | 사람이 직접 구현해야 함 |
| wontfix | wontfix | 처리하지 않기로 결정함 |

스킬이 역할을 지칭하면 이 표의 GitHub 라벨을 사용한다.
이름을 바꿀 때는 GitHub 라벨 열을 실제 트래커와 함께 갱신한다.
