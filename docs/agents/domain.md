# Domain Docs

Clipback은 single-context 구조를 사용한다.

- 용어집: 저장소 루트의 `GLOSSARY.md`
- 아키텍처 결정 기록: `docs/adr/`

## 코드 탐색 전에 읽기

`GLOSSARY.md`와 작업 영역에 관련된 ADR을 먼저 읽는다.
해당 문서가 없으면 별도 경고나 생성 제안 없이 작업을 계속한다.
용어와 결정이 실제로 확정될 때 `domain-modeling`으로 필요한 문서를 만든다.

## 용어 사용

이슈 제목, 설계 제안, 가설, 테스트 이름에는 용어집에 정의된 표현을 사용한다.
필요한 용어가 없으면 기존 프로젝트 표현을 먼저 확인하고,
실제 용어 정의가 필요한 경우 `domain-modeling`에서 다룬다.

## 결정 충돌

제안이 기존 ADR과 충돌하면 해당 ADR과 재검토 이유를 명시한다.
기존 결정을 설명 없이 덮어쓰지 않는다.
