사용자 승인 문구입니다(2026-11-18 "승인", 조율 전달). 오픈채팅방 공지와 스토어 짧은 안내 모두 배포 세션이 쓴 초안 그대로입니다. 원본은 CHANGELOG `## 앱 0.7.0` 절(추가 3, 개선 1, 수정 7)입니다. 오픈채팅방(Android 테스터) 기준으로 `[iOS]` 항목(#406 심사 설정, #367 iOS 공유 시트 뒤 화면)은 넣지 않았습니다. 공지 날짜는 실제로 공지하는 날로 바꿉니다.

- 오픈채팅방 공지: 아래 승인 문구(초안 그대로). 실제 게시 여부·날짜는 사용자 보고 전이라 미확인. 추가 셋을 `🆕`에, 앱 수정 여섯을 `🔧`에 넣었습니다. 시트 줄이 있는 제보 항목(77, 79, 91, 106, 122, 123)이 있어 "제보 감사합니다"를 둡니다.

```text
[허투루 0.7.0 업데이트 안내] 2026-11-18

🆕 새로 생긴 것
- 홈의 종 버튼과 마이 → 고객지원 '공지사항'에서 사용 안내 글 '허투루 100% 활용법'·'허투루 사용이 처음이라면?'을 볼 수 있어요. 홈 '이번주 허투루 픽' 끝의 '허투루 100% 활용법' 카드를 눌러도 열려요.
- 콘텐츠 하나를 여러 카테고리에 넣을 수 있어요. 콘텐츠 관리의 '카테고리 변경'에서 여러 개를 체크하고 '선택 완료'를 누르면 돼요.

🔧 고친 것
- 화면 아래에 잠깐 뜨는 안내가 화면 폭 전체의 띠 대신 양옆에 여백이 있는 둥근 상자로 바뀌었어요. 아래로 밀어 닫을 수 있어요.
- 빨강·주황·노랑·초록·파랑·보라 카테고리 배지가 디자인에 맞는 연한 배경과 진한 글자색으로 보여요.
- 홈 카테고리 칩의 글자가 테두리에 붙어 보이던 문제를 고쳤어요. 이름이 긴 칩도 글자가 다 보여요.
- 아카이브·카테고리 목록·즐겨찾기 화면 위쪽의 돋보기가 홈과 같은 크기로 보여요.
- 글자 크기를 크게 키우면 정렬 메뉴의 '즐겨찾기 우선' 줄이 오른쪽으로 넘치던 문제를 고쳤어요.
- 공유 메뉴로 Instagram·YouTube가 아닌 링크가 여러 개 넘어오면 '한 번에 링크 하나만 공유해 주세요'가 뜨던 문제를 고쳤어요. 이제 Instagram 또는 YouTube 링크만 저장할 수 있다고 안내해요.
```
