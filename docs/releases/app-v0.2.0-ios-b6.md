이번 대상은 iOS TestFlight 검증입니다. App Store의 기존 `1.0` 제출 준비 상태와 Android 배포는 이번 후보의 공개 완료로 처리하지 않습니다. 상세 스토어 관찰·미실행 근거는 위 작업 이력에 보존합니다.

## 진행 기록과 중단·복구

빌드·업로드·공개, 재업로드, 중단·롤백을 시간순으로 추가합니다. 같은 산출물의 재시도는 이 기록에 이어 적습니다.
소스를 수정한 새 후보는 새 파일로 만들고 이전 후보 링크를 남깁니다. 기존 실패·검증 결과를 새 후보의 성공으로 바꾸지 않습니다.
재업로드 시 플랫폼·버전·빌드 번호·SHA·산출물·처리 결과를 적고,

## 빌드·업로드 전에 남은 확인

- 계정 소유자가 App Store Connect에 표시된 갱신된 Apple Developer Program 계약을 별도 검토해야 한다. 이번 작업에서는 계약을 수락하지 않았다.
- 기존 최고 빌드 5는 수출 규정 정보 누락 상태다. 새 산출물의 실제 암호화 사용을 확인하고 해당 제출에 필요한 정보를 별도로 결정한다. 기존 빌드의 답변을 임의로 변경하거나 새 빌드의 답변을 추정하지 않는다.
- 고정한 소스로 목표 버전·빌드의 산출물을 만든 뒤 서명·권한·API 기본 주소·원본 열람·카테고리 복구·홈·통계를 iOS Simulator에서 확인한다. 실기기 검증·테스터 배정은 별도 요청 범위에 맞춰 진행한다.
- 소스를 수정해야 하면 이 후보의 SHA·기존 근거를 덮어쓰지 않고 새 빌드 번호로 후보를 준비한다. 빌드 6을 업로드하기 전에도 최신 스토어 이력과 원격 예약을 다시 확인한다.
