# 스크린샷 원본의 계정 기반 보관

스크린샷의 작은 글자와 원본 재열람을 보장하기 위해 사용자가 제공한 원본 이미지를 변환 없이 보관한다.
앱 재설치나 기기 변경 후에도 같은 로그인 계정으로 다시 열람할 수 있도록 서버 측 보관본을 유지하며,
기기의 캐시는 유일한 보관본으로 사용하지 않는다. 압축본만 보관하거나 OCR 텍스트만 남기는 방식은
원래 이미지로 되돌릴 수 없으므로 선택하지 않는다.

초기 이미지 보관·전송·백업 비용은 서버·DB·AI 비용과 별도로 월 1만 원 안팎을 설계 목표로 삼는다.
이는 결제 승인이나 자동 비용 상한이 아니다. 구체적인 보관·한도·백업 정책과 확인 필요 항목은
[이미지 보관 정책](../image-storage-policy.md)을 따른다.
이 결정은 2026-10-23 설계 인터뷰에서 합의했으며 구현·배포 완료를 의미하지 않는다.
