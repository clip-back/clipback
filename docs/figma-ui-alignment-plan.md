화면별 현재 기준 표의 근거 링크에서 Before/After/Figma 출처·기종/OS·검사 수치·실패·재촬영·미검증 범위를 확인합니다. [전체 이력](history/README.md)과 [정리 전 목록·보존 대조](history/2026-10-22-general-docs-structure.md#followup-docs-finish)를 함께 사용합니다.
과거 비교·빌드·자동 검사의 통과는 새 확대 상태·운영 공급자·실기기의 성공으로 확대하지 않습니다. 홈 북마크 부모 탭 전달, 낮은 소개 viewport 넘침, 원본 누락과 보관 원본 사용·Figma 조회 실패도 각 당시 이력에 보존합니다.

## 기록과 변경 규칙

화면별 변경·Before/After/Figma 출처·플랫폼 결과·실패·한계는 같은 작업 기록에 한 번만 적습니다.
현재 화면 계약이나 확인 필요 항목이 달라질 때 이 문서를 갱신하고 해당 기록을 연결합니다.
이전 Figma 캐시는 현재 원본의 대체 자료로 사용하지 않습니다.

## 사진 저장 수동 재시도 (#235)

기존 지연 토스트 문구·외형과 D09 `111:4865` 결과 화면을 유지한다. 사진 실패 `142:4721`·분석 지연 `142:4898`은 적용하지 않는다.
자동 재확인·결과 미확인/확인 중 새 안내·새 버튼은 후속 디자인 확인이 필요하며 이번 구현에서 제외한다.
2026-11-05 사용자 결정에 따라 저장 요청 중 사진 선택만 기존 비활성 방식으로 잠근다. 시간 초과 뒤에는 다시 선택할 수 있다.
처리 중·결과의 스크린샷 썸네일만 상단 정렬하고 크기·위치는 유지한다. 선택 전 미리보기에는 적용하지 않는다.
결정 원문과 작업 기록은 [#235 이력](history/2026-11-05-photo-save-retry.md)에 둔다. 최종 플랫폼별 화면 확인은 아직 완료하지 않았다.

## 링크 저장 제한 시간 (#319)

링크 저장도 사진 저장의 기존 지연 토스트 문구·외형을 쓴다. 다만 2026-11-10 사용자 결정으로 공용 안내창의 최대 줄 수만 2에서 3으로 늘렸다([디자이너 확인 항목](#figma-pending-toast-lines)). 제한 시간(저장 버튼부터 20초) 전에는 D04 `111:5006` 처리 중 화면을 그대로 두고,
다시 저장해 성공하면 기존 결과 화면(D09 `111:4865`)을 보인다. 2026-11-09 섹션 `111:3379` 재조회에서도 링크 지연 전용 기준은 확인되지 않았다.
사진 분석 지연 `142:4898`과 추출 시간 초과 와이어프레임은 적용하지 않는다. 제한 시간 전 안내와 공유 준비 실패 띠는
[디자인 확인 필요](#figma-pending-link-slow)에 둔다. 양 플랫폼 변경 전·후 촬영과 Figma 기준 유무는 [#319 이력](history/2026-11-10-link-save-timeout.md#화면-확인)에 있으며, 사용자 시각 판정은 아직 받지 않았다.
