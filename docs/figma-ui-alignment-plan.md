- 작성일: 2026-10-13. 최신 디자인 기준 전환일: 2026-10-14. 저장 결과·확대 레이아웃·하단 배치 작업 갱신일: 2026-10-15.

  최신 `261008` 기준의 문서·노드 대응과 UI-06의 저장 결과 문구·제출 입력 고정을 적용했다.
  `a14111f` 당시 남긴 저장 화면 확대 넘침은 아래 후속 작업에서 사용자 확정 기준으로 수정하고 자동·양 플랫폼 실행 검증을 마쳤다.
  이번 후속 작업에서 저장 화면의 본문·버튼 겹침과 하단 안전 영역을 아래 사용자 확정 기준으로 수정하고 자동·iOS/Android 실행 검증을 마쳤다.
  새 디자인 전체의 코드 적용·실행 비교는 미완료다.
- 승인된 방향은 기존 화면을 Figma에 맞추며 카테고리를 삭제해도 콘텐츠를 보존하는 것이다.
  첫 구현 커밋 `6f8fa73`은 공통 텍스트 스타일과 제목·버튼, 홈 커밋 `cc73b21`은 아래 확정된 홈 영역에 한정한다.
  확대 레이아웃 커밋 `d01873c`에서 사용자가 승인한 하단 탭 최대 두 줄·높이 확장과 최근 카테고리 이름/시각의 한 줄 말줄임을 적용했다.
  `a9eb69d`는 공통 하단 탭의 실제 OS 안전 영역 합산과 카드 다시보기의 하단 보호에 한정한다.
- 이전 기준에서 홈 상단·소개·카드·카테고리 칩·페이지 점과 확인된 빈 상태를 적용했다.

- 아래 나머지 순서와 수정 방향은 구현 제안이다. 게스트 정책 변경이나 M 보완안까지 일괄 승인된 것으로 간주하지 않는다.

현재 디자인 기준은 [허투루 UIUX 디자인의 `261008`](https://www.figma.com/design/b2lmAo9VtbL6Qi0mzX5IMu/?node-id=912-13961)이다.
파일 키는 `b2lmAo9VtbL6Qi0mzX5IMu`, 페이지는 `WireFrame & UI`(`3:5961`), 섹션은 `261008`(`912:13961`)이다.
사용자가 2026-10-14 이 기준을 지정했으며 실제 섹션의 부모 페이지도 Figma에서 확인했다.
Figma는 변경될 수 있으므로 구현 직전에 대상 프레임의 디자인 컨텍스트와 스크린샷을 다시 확인한다.

섹션에는 A~K의 기존 화면과 오른쪽의 M 번호 보완 와이어프레임, 공통 L 상태가 함께 있다.
[보완 UI 안내](https://www.figma.com/design/b2lmAo9VtbL6Qi0mzX5IMu/?node-id=912-15270)는
M을 신규 제안으로, 각 항목을 필수·정책 확인·조건부로 구분한다.
여기서 ‘필수’ 표시는 디자인 문서의 분류이며 제품 범위에 대한 별도 승인이나 구현 완료를 뜻하지 않는다.
와이어프레임은 상태와 동선의 근거로 사용하고 최종 시각 스타일은 기존 디자인과 함께 확정한다.

이전 기준은 [별도 파일의 `261007`](https://www.figma.com/design/svNWsTFh8Ws1Mpt8XQIcrN/?node-id=111-3379)이었다.
기존 커밋의 `111:*`·`120:*`·`142:*` 노드와 조회 시각·검증 숫자·비교 원본은 그때의 근거로 보존한다.
새 기준의 코드 일치 또는 이번 검증 결과로 바꾸지 않는다.

기존 [Figma 캐시](../frontend/design_cache/figma_624_16572.md)는 현재 파일과 같은 파일 키의
`업데이트_260730`(`624:16572`) 섹션을 2026-09-07에 기록한 자료다. 최신 `261008` 근거로 사용하지 않고 과거 구현 배경으로만 참고하며,
그 안의 mock 저장·사진 선택 설명을 현재 코드의 동작으로 사용하지 않는다.

## 첫 구현 커밋의 적용 범위

이 절의 구현 범위와 아래 과거 검증 절은 당시 `svNWsTFh8Ws1Mpt8XQIcrN / 261007` 기준의 기록이다.

  `AppText.sectionTitle`은 기본 본문 스타일을 상속하지 않으며 `height`를 지정하지 않아

  `PrimaryButton`의 기본·사용자 지정 foreground를 유지한다. 버튼 높이·모서리·생성자·콜백은 유지한다.

이 분석과 다음 커밋별 검증은 이전 `261007` 파일을 사용한 기록이다.
