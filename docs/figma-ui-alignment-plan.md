# Figma 화면 맞춤 계획

## 상태와 비교 기준

- 작성일: 2026-10-13.
- 작업 브랜치: `feature/figma-ui-alignment`.
- 비교 기준: 로컬 `main`의 `5389f48`(모바일 공유 PR #56 병합). 원격 최신 상태를 검증한 기록은 아니다.
- 현재 상태: **공통 스타일 첫 구현 완료, 1단계 부분 완료**.
- 승인된 방향은 기존 화면을 Figma에 맞추며 카테고리를 삭제해도 콘텐츠를 보존하는 것이다.
  첫 구현 커밋은 공통 텍스트 스타일과 이를 사용하는 제목·버튼에 한정한다.
- 홈 배치·문구·일러스트·페이지 점·추천 연결은 미착수다. API·데이터 모델·저장·삭제 처리의 변경은 없다.
- 아래 나머지 순서와 수정 방향은 구현 제안이다. 게스트 정책 변경이나 M 보완안까지 일괄 승인된 것으로 간주하지 않는다.

디자인 기준은 [허투루 UI 디자인의 Page 1](https://www.figma.com/design/svNWsTFh8Ws1Mpt8XQIcrN/?node-id=0-1)이다.
파일 키는 `svNWsTFh8Ws1Mpt8XQIcrN`, 기준 섹션은 `261007`(`111:3379`)이다.
Figma는 변경될 수 있으므로 구현 직전에 대상 프레임의 디자인 컨텍스트와 스크린샷을 다시 확인한다.

페이지에는 A~K의 기존 화면과 오른쪽의 M 번호 보완 와이어프레임이 함께 있다.
[보완 UI 안내](https://www.figma.com/design/svNWsTFh8Ws1Mpt8XQIcrN/?node-id=118-3408)는
M을 신규 제안으로, 각 항목을 필수·정책 확인·조건부로 구분한다.
여기서 ‘필수’ 표시는 디자인 문서의 분류이며 제품 범위에 대한 별도 승인이나 구현 완료를 뜻하지 않는다.
와이어프레임은 상태와 동선의 근거로 사용하고 최종 시각 스타일은 기존 디자인과 함께 확정한다.

기존 [Figma 캐시](../frontend/design_cache/figma_624_16572.md)는 다른 파일의
`업데이트_260730` 섹션을 2026-09-07에 기록한 자료다. 과거 구현 배경으로만 참고하며,
그 안의 mock 저장·사진 선택 설명을 현재 코드의 동작으로 사용하지 않는다.

## 변경을 나누는 기준

| 구분 | 포함 범위 | 진행 조건 |
| --- | --- | --- |
| 화면 맞춤 | 여백, 크기, 색, 글자, 아이콘, 일러스트, 문구, 기존 동선의 배치 | 기존 데이터·인증·저장 계약을 유지하며 대상 화면별로 구현 |
| 기능 연결 | 관심사 전달, 추천 연결, 실제 최근 검색어, 원문·썸네일, 오류 복구 | 현재 API와 상태 소유자를 확인하고 필요한 계약을 먼저 정의 |
| 신규 보완안 | M 화면의 중복 안내, 정보 수정, 문의 접수, 카드 완료 등 | 구현할 항목을 선정하고 기존 기능과 겹치는 부분을 재사용 |
| 정책 확인 | 삭제 범위, 게스트 이전, 저장 시점, 총개수 등 | 아래 결정 목록을 해소한 후 의존 작업 진행 |

회색·흰색·노란색 기본 색상, Pretendard, 하단 탭과 추가 버튼, 콘텐츠 목록 카드,
아카이브 탭, 카테고리 생성 시트, 상세 섹션 순서와 카드 스와이프는 이미 구현돼 있다.
기존 위젯과 ViewModel·Repository 구조를 재사용하고 화면 전체를 일괄 재작성하지 않는다.
