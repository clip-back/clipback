# 로그인 화면 아래 약관 문구와 이용약관·개인정보처리방침 링크 (#412)

2026-11-17, 브랜치 `feat/login-terms-links`. 시작 커밋 `baa9e88`, 구현 커밋 `e700ed2`, 검수 반영 커밋 `7100f0a`.

## 문제

- 일반 로그인 화면(A02)에 Figma의 약관 문구 "계속하면 허투루의 서비스 이용약관에 동의하며, 개인정보처리방침을 확인한 것으로 간주합니다."가 없었다. 2026-10-18 로그인 화면 맞춤 때 문안·주소가 정해지지 않아 미뤘다(`figma-current-03`·`figma-pending-03`).
- 두 문서의 웹 주소가 정해져(#349) 로그인 전에 약관과 처리방침을 볼 방법을 넣는다(2026-11-16 회의 결정 "'서비스 이용약관', '개인정보처리방침' 누르면 각 링크로 이동").

## 사용자 결정

이슈 #412 본문의 결정 1–9, 2026-11-17 사용자 원문 "모두 추천대로".

1. Figma A02 문구를 새로 넣고 두 단어를 링크로 한다.
2. 링크 표시는 Figma대로 밑줄 없이 두 단어만 Pretendard SemiBold `#484848`.
3. 문구 아래 끝 = 안전 영역 아래 끝 − 11, 게스트 글자 아래 끝 = 문구 위 끝 − 30. #377의 "모든 배율 − 83"은 "1배 − 83"으로 바뀌고, 1.3배 기존 테스트 2건의 기대값 584 → 572를 허용한다.
4. Figma 강제 줄바꿈을 유지한다(폭 320·1.3배는 4줄).
5. 실패 안내 문구는 링크별 새 문구다.
6. 실패 안내가 두 단어를 덮는 것은 그대로 두고 '디자인 확인 필요'에 올린다.
7. 스크린리더는 두 단어를 링크로 읽는다.
8. 로그인 진행 중(busy)에도 두 단어를 누를 수 있다.
9. 누르는 영역은 단어 글자 상자뿐이며, 권장 크기(44·48)에 못 미치는 것을 '디자인 확인 필요'에 기록한다.

## 바꾼 것

- `frontend/lib/features/account/contact_form.dart`: 이용약관 주소 `https://huturu-app.github.io/terms`와 `openTermsOfService()`. 처리방침과 같은 외부 앱 열기(같은 주소를 여는 중 다시 누르면 무시, OS 거절·예외는 실패). 마이 '이용약관 및 개인정보' 줄의 주소·문구·동작은 그대로다.
- `frontend/lib/features/auth/login_screen.dart`: 일반 로그인 화면 맨 아래에 약관 문구(`Text.rich`, 두 단어에 `TapGestureRecognizer`). 아래 여백은 11로 고정하고, 게스트 누르는 영역과 문구 사이는 30 − (44 − 게스트 글자 높이)/2(1배 17)다. 열기 실패면 '서비스 이용약관을 열지 못했어요. 다시 시도해 주세요.' / '개인정보처리방침을 열지 못했어요. 다시 시도해 주세요.'를 공통 화면 아래 안내(`noticeSnackBar`, 새 안내가 이전 안내를 대신함)로 띄운다. 실패 안내 처리는 마이와 공유하지 않고 같은 규칙으로 로그인 화면에 둔다(구현 판단, 마이 코드 무변경).
- `docs/figma-ui-alignment-plan.md`: `figma-current-03`(약관 문구·링크·위치), `figma-current-04`(게스트 글자 1배 − 83, 문구 높이만큼 위로), `figma-pending-03`(앵커 유지, 결정 6 겹침·결정 9 누르는 영역).
