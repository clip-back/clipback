# 홈 상단의 옛 "저장한 정보가 없어요." 영역 삭제와 직전 상단 유지

최초 기록일: 2026-11-03 KST. 이슈 [#217](https://github.com/clip-back/clipback/issues/217)(팀 피드백 시트 26·36번), 시작 커밋 `d1ec34f`,
작업 브랜치 `fix/home-hero-fallback`.

## 문제와 결정

- 홈 상단은 저장한 콘텐츠가 있으면 C01 `111:3584`, 저장 0으로 확정되면 C02 `111:3681`이다. 그런데 칩 로딩 중, 칩 결과 빈 카테고리,
  오류처럼 어느 쪽인지 확정되지 않은 동안 Figma에 없는 옛 영역("저장한 정보가 없어요. / 지금 하나만 저장할까요? / 저장 방법 보기 →")이
  나왔다. 옛 영역은 C01·C02보다 32 높아(1.0배 상단 전체 236 대 204) 칩을 바꿀 때 아래 내용이 내려갔다 올라왔다.
- 2026-11-03 사용자 결정(이슈 '결정' 절):
  - 확정되지 않은 동안(칩 로딩 중, 칩 결과 빈 카테고리, 오류, 다시 불러오기 중)에는 직전 상단을 유지하고, 직전을 모르면 C01을 보인다.
  - 직전 상단은 앱 상태에 두어 다른 탭에 다녀와도 유지한다.
  - 옛 영역은 지운다. C01 버튼은 항상 '오늘의 콘텐츠'를 열고, C02 버튼은 지금처럼 저장 화면을 연다.
- 2026-11-03 사용자 결정 A: 계정 전환·로그아웃 때 직전 상단 기억을 지우지 않는다(추가 코드 없음). 근거: 새 계정은 홈에 들어가기 전에
  첫 홈 목록을 끝까지 불러오고 실패하면 홈에 들어가지 않으므로(`account_initialization_action.dart`), 홈이 보일 때는 '카드 있음'
  또는 '저장 0 확정'으로 바로 정해져 이전 계정 기억이 화면에 나올 경로가 없다. 실제로 일어나지 않는 상황의 방어 코드는 넣지 않는다.

- 쓰지 않게 된 `Assets.homeCharacter` 상수를 지웠다. 그림 `assets/figma/home-character.png`는 루트 `README.md` 8행이 쓰므로 남겼다.
