## #414 카테고리 배지 연한·진한 색을 Figma 색 짝으로 (팀 피드백 시트 79 앱)

구현 커밋 `331c9ec`.

### 문제

카테고리 배지의 연한 배경·진한 글자 색을 앱이 카테고리 기본색에서 계산해, Figma "카테고리 색상 코드" `428:4712`에 색마다 정해진 짝과 달랐다.

### 사용자 결정

- 2026-11-16 팀 회의: "카테고리 6개 색 짝도 피그마에 옮겨서 현규 태그함". 2026-11-17 "모두 추천대로": 6색 배지를 `428:4712` 짝으로 맞추고(이 이슈), 기본 카테고리 6개의 서버 색은 별도 이슈·PR로 한다.
- 2026-11-17 후속 선택지 a 승인("응"): 팔레트 1–6번만 짝으로 바꾸고 짝 없는 색은 지금 계산을 그대로 둔다.
- 이슈 본문의 "기본색 × 0.72" 진한 색 설명(예 빨강 `#B84756`)은 실제 화면과 다르다. `deepCategoryColor`는 0–1 실수 채널에 0.72를 곱해 반올림하므로 채널이 0 또는 1이 되어, 시작 커밋 실측 배지 글자는 거의 검정이다(분홍 `#FF010101`, 진초록·`#059669` `#FF000000`). 결정 a에 따라 이 실측값을 "지금 계산"으로 유지했고 이슈 본문은 고치지 않았다. 계산 의도는 팀 피드백 시트 124에서 0.6.2 뒤에 다룬다.

### 바꾼 것

- `frontend/lib/shared/category/category_colors.dart`: `categoryBadgeColors`를 두어 카테고리 색이 앱 팔레트 1–6번(`#FF6277`·`#FFA24B`·`#FFD75C`·`#5BD89D`·`#64B5F6`·`#B9AAFF`, ARGB 전체 비교)이면 같은 칸 Figma 짝(배경 3줄 연한, 글자 2줄 진한)을, 아니면 기존 계산(배경 20%, 글자 `deepCategoryColor`)을 돌려준다.
- 서버 응답 매핑(`content_mapper.dart`)과 생성·수정 시트가 저장 직후 만드는 모델(`category_sheets.dart`)이 모두 이 함수를 쓴다. 그래서 시트 쪽 짝 없는 색도 서버 응답 뒤와 같아졌다(배경 22% → 20%, 생성 시 글자 = 기본색 → 기존 계산).
- 팔레트 8색 값·미분류 회색·새 카테고리 첫 선택 색은 그대로다.
- `docs/figma-ui-alignment-plan.md`: 현재 기준 `figma-current-category-badge-colors`, 디자인 확인 필요 `figma-pending-category-badge-unpaired`(분홍·초록2 칸 짝 없음).
- 새 테스트 `frontend/test/category_badge_color_test.dart`(38개): 서버 색 → 모델(소문자 `#ffa24b` 포함), 홈 카드·상세에 그려진 배지 배경·글자, 생성·수정 시트 저장 직후 모델 = 서버 매핑 값. 기존 테스트·기기 측정 helper는 바꾸지 않았다(이슈 허용 표 모두 "바꾸지 않음").

### 검사
