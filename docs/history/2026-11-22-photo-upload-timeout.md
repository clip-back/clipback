# 앱 사진 저장 시간 제한 30초 (#459)

팀 피드백 시트 145. 앱 저장 화면의 사진 업로드가 서버 응답을 10초만 기다려, 서버가 저장에 성공해도 화면에는 지연 안내가 뜰 수 있었다.

## 결정과 변경

- 사용자 결정 Q1 "A. 업로드 단계별 10→30초만 (추천)": 사진 업로드의 응답 시작(머리) 대기와 응답 본문 수신에 각각 30초 제한을 둔다(`frontend/lib/clipback_api.dart` `_uploadTimeout`). 공용 10초(다른 API·원본 조회·인증 갱신)와 링크 저장 20초는 그대로다. 401 뒤 재전송도 같은 업로드 요청이라 다시 각각 30초다.
- 결정 Q2 "그대로 두고 디자인 목록에 추가 (추천)": 화면은 바꾸지 않고 [Figma 화면 맞춤 계획](../figma-ui-alignment-plan.md)의 "링크 저장이 오래 걸릴 때" 행에 사진 30초 대기를 더했다.
- 동작 문서 [behavior.md](../frontend/behavior.md), `CHANGELOG.md` 미배포 개선(단계별 제한으로 표기, 검수 낮음 1건 반영).

## 테스트

- 재현: `screenshot_auth_test.dart` "photo answered at 29 seconds shows the saved result". 변경 전 코드(be12e77)에서 결과 화면 0개로 실패, 변경 후 통과.
- 이슈 허용 표 안의 기존 테스트 시점만 바꿨다: 11→31초 3건, 9→29초 2건(이름 `ten`→`thirty`, 30초 지연 문구·요청 1건 단언 유지), L6 사진 갈래 10→30초 2건. 인증 갱신 10초·원본 조회 10초·링크 20초 테스트는 바꾸지 않고 통과.
