## 원인과 구현

- 잠긴 별·더보기는 누르기 처리를 비워(`onPressed`/`onTap: null`) 비활성으로 만든다. 누르기 처리가 빈 `IconButton`·`InkWell`은 탭을 받지 않아, 탭이 아래 카드의 상세 열기로 넘어갔다.
- `LockedTapBarrier`(`frontend/lib/shared/widgets/buttons.dart`)를 더했다. 잠겼을 때만 버튼 자리에서 탭을 받아 아무것도 하지 않는다.
  의미 트리에는 새 동작을 넣지 않고(`excludeFromSemantics`), 버튼의 겉모습·누르는 영역·비활성 상태는 그대로다.
- 적용 자리: `SvgIconButton`(홈 카드 별, 일반 목록 카드 별·더보기, 상세 상단 별·더보기), 전체보기 모양 카드 버튼(아카이브 전체보기·카테고리 목록·미분류·즐겨찾기·검색), 카드 다시보기 별.
- 잠금은 카테고리 이동·삭제 중에도 같은 값(`isMutating`)으로 걸리므로, 그때도 잠긴 별·더보기를 눌러 상세가 열리지 않는다. 동작 문서와 CHANGELOG에 적었다.
- 별·더보기 바깥 카드 영역을 누르면 처리 중에도 상세가 열리는 동작, 즐겨찾기·이동·삭제의 잠금 순서·실패 복귀는 바꾸지 않았다.
