## 검증 환경 준비

- 운영 DB와 분리한 PostgreSQL 17 클러스터와 티켓별 합성 테스트 DB를 로컬에 만들었다.
- S3 경계는 moto 대역을 사용하고, 실제 격리 복원용 Docker와 합성 S3 이미지를 준비했다.
- 기기 기준 화면은 iPhone 16 Pro / iOS 18.6, Android 13 / API 33 에뮬레이터에서 네 장 수집했다.
  현재 제품 위젯과 합성 데이터를 사용한 프리뷰는 API·Bucket·OAuth 검증으로 간주하지 않는다.
- 호스트 자원 압박으로 Android System UI가 멈췄다. 이 실패 화면을 정상 제품 증거로 사용하지 않았고,
  작업에서 시작한 Docker를 잠시 멈추고 에뮬레이터 GPU 설정을 바꿔 기준 화면을 확보했다.
  이후 Docker를 다시 시작해 합성 복원을 검증했다.
- 실제 실행 결과·스크린샷·전체 통합 검사와 최종 리뷰는 완료 시 이 기록에 보충한다.

## 실행 경계

운영 Bucket 생성, 운영 변수·배포·사용자 자료 이관, 실제 OAuth·실기기, 푸시·PR은 실행하지 않았다.
실제 공급자 검증과 합성 S3·로컬 검사, 운영 백업과 합성 복원은 별도로 보고한다.
