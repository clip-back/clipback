# 유튜브와 인스타그램 자동 요약 조건 통일 (#452)

2026-11-21, 기준 커밋 `7b1dd40`에서 시작했습니다. [이슈 #452](https://github.com/clip-back/clipback/issues/452)

## 변경

- 첫 구현 `bacce89`에서 유튜브와 인스타그램 자동 요약에 공통 한국어 지시와 요청 스키마 상수를 적용했습니다. 핵심 한 줄은 40자 안팎, 요점은 하나에 80자 안팎으로 근거만큼 1–10개를 요청합니다. 인스타그램의 출력 상한은 4,000토큰입니다.
- 서버는 요점 전체의 타입을 확인하고 기호와 공백을 정리한 뒤 앞 10개를 남깁니다. 합친 링크 요약이 1,000자를 넘으면 뒤 요점부터 하나씩 뺍니다. 요점 하나만 남겨도 1,000자를 넘으면 `invalid_response`입니다.
- 직접 입력하거나 이미 저장된 1,001자 요약은 전문을 조회할 수 있습니다. 배포 전에 대기했거나 배포 뒤 재시도되는 작업은 저장 당시 모델로 실행 시점의 조건을 쓸 수 있습니다. 사진의 길이 정책은 #453에서 적용합니다.
- 검수 뒤 두 원래 지시문에 있던 요점 지어내기 금지와 핵심 사실·수치·조건 보존을 공통 지시에 명시했습니다. 두 공급자에 전송한 공통 부분을 뽑아 두 문장이 있는지 검사합니다.
- 사용자 승인으로 기존 공급자 응답 테스트 두 건의 입력 길이를 501자에서 1,001자로 조정했습니다. 오류 코드, 재시도 여부와 사용량 단언을 유지했습니다.

## 검증

- 첫 구현에서 링크와 사진 소비자 부분 검사 350건과 로컬 PostgreSQL 저장·조회 API 검사 2건이 통과했습니다.
- 검수자는 첫 구현을 대상으로 로컬 PostgreSQL에서 저장·조회 API와 저장 계약을 합쳐 81건 통과를 확인했습니다. 작업자는 검수 반영 뒤 공급자 요청, 사진 소비자, API와 저장 계약·기준선을 포함해 434건 통과, 건너뜀 0건을 확인했습니다. 두 저장 고정 테스트 파일은 그대로 실행했습니다.
- 공통 지시의 누락 문구를 단언한 테스트는 반영 전에 실패했고, 반영 뒤 위 부분 검사에서 통과했습니다.

### 변형 실험

첫 구현의 서버 판정을 한 번에 하나씩 바꿔 `tests/integrations/test_summary_result_validation.py`의 대상 검사를 각각 실행했습니다. 다섯 실험 모두 종료 코드 1과 아래 단언 실패를 확인했습니다. 코드를 원복하고 같은 경계를 두 클라이언트에서 검사한 8건은 통과했습니다.

| 임시 변형 | 실패한 단언 |
| --- | --- |
| 뒤 대신 앞에서 요점 빼기 | `youtube-drop-c`에서 남은 요점 문자열이 다름 |
| 요점을 빼는 대신 1,000자에서 자르기 | `youtube-drop-c`에서 마지막 글머리 기호가 남음 |
| 요점이 하나 남으면 멈추는 조건 제거 | `youtube-joined-1001`에서 오류 없이 핵심 한 줄만 반환 |
| 요점 상한 10개를 5개로 되돌리기 | `youtube-first-ten-of-eleven`에서 요점 6–10이 빠짐 |
| 앞 10개를 고른 뒤 타입 검사 | `youtube-eleventh-point-null`에서 오류 없이 통과 |
