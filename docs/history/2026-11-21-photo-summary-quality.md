# 사진 요약에 공통 요약 조건 적용 (#453)

2026-11-21, 기준 커밋 `30acf54`에서 시작했습니다. 첫 구현 커밋은 `a24ec89`입니다. [이슈 #453](https://github.com/clip-back/clipback/issues/453)

## 변경

- 스크린샷 OCR 요청에 유튜브·인스타그램과 같은 한국어 요약 지시를 넣었습니다. 사진 속 글자는 읽는 순서대로 원문 언어를 유지해 5,000자까지 추출합니다. 핵심 한 줄은 40자 안팎, 요점은 하나에 80자 안팎으로 0–10개를 요청합니다. 짧은 글의 사실이 핵심 한 줄에 모두 담기거나 요점 근거가 없으면 핵심 한 줄만 씁니다.
- 서버는 새 사진 요약이 1,000자를 넘으면 뒤 요점부터 빼고, 핵심 한 줄만으로 넘으면 첫 1,000자를 남깁니다. 빈 핵심 한 줄이면 기본 요약 문구로 저장하며 유효한 제목과 추출 글자는 사용합니다. 제목은 120자까지 남깁니다.
- 안내 문서에 세 출처의 공통 조건과 사진 전용 예외를 기록했습니다.

## 검수 판단

| 지적 | 반영 결과 |
| --- | --- |
| 사진 요점 개수와 짧은 글 | 사진 전용 지시에 0–10개 범위와 핵심 한 줄로 충분한 경우를 명시했습니다. 세 공급자 요청의 공통 구간 일치와 사진 예외의 위치를 검사했습니다. |
| 태그 지시 | #450의 범위에 따라 OCR과 일반 카테고리 추천이 함께 쓰는 `TAG_PROMPT` 문구를 유지했습니다. |
| 1,000번째 글자가 공백 | #450의 순서대로 먼저 공백을 정리하고 최초 1,000자를 반환합니다. OCR 반환값은 끝 공백을 포함해 1,000자이고, 저장 응답은 기존 앞뒤 공백 정리를 거쳐 999자임을 확인했습니다. 검수자의 경계 검사는 공유 검사 자원이 사용 중이어서 실행되지 않았습니다. |
| 공통 정리 함수의 `for_link` | 링크와 사진 호출 모두 값을 명시합니다. 같은 루프에서 최소 요점 수를 링크 1개·사진 0개로 적용하는 구조를 유지했습니다. |
| OCR 테스트의 원본 메서드 참조 | 테스트는 공용 대역 대신 원본 메서드로 들어갑니다. 자료형 오류가 `invalid_response`로 기록되는 행과 정상 응답별 저장 결과·추출 글자 단언으로 확인했습니다. |
