## 확인한 검증 경계

사용자는 기존 실제 앱·HTTP 대역·메모리 세션 저장소 통합 테스트를 주 경계로 사용하는 데 동의했습니다.
기존 앱 시작·세션 복원 테스트의 지연 응답·가상 시간·인증 갱신 경계를 우선 사용하고, Repository 회귀 검사를 유지하며 네이티브 화면 검증을 보완합니다.
이 확인은 스킬의 “Check with the user that these seams match their expectations.” 지침에 따른 것으로 기존 정책을 다시 결정한 것이 아닙니다.

앱 시작·세션 복원, 사용자 Repository, 계정 통계 회귀 테스트와 현재 통계 조회·계정 표시·초기화 연결을 읽었습니다.
미확인 상태의 0 표시와 프로필·통계 결합에 관한 기존 기대값이 새 계약에 맞게 바뀌어야 함을 명세에 기록했습니다.

## GitHub 게시 상태

- 대상: `clip-back/clipback` GitHub Issues.
- 예정 제목: `[Spec] 마이 통계 조회 상태·복구와 마지막 확인값 표시`.
- 예정 라벨: `ready-for-agent`.
- 같은 주제의 기존 이슈 검색 결과가 없고 해당 라벨이 존재하는 것을 조회했습니다.
- 이슈 생성은 자동 승인 검토에서 거부되었습니다. 본문을 외부에 게시하는 원격 변경이며 사용자가 해당 본문 게시를 명시적으로 승인하지 않았다는 이유입니다.
- 이슈는 생성하지 않았으며 우회 수단으로 다시 게시하지 않았습니다. 본문을 로컬에서 검토할 수 있도록 저장했고, 해당 본문 게시 승인 대기 상태입니다.
