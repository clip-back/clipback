2026-11-09 사용자 "추천대로 해줘": 로컬 `backend/.env`의 `OCR_TIMEOUT_SECONDS`만 운영과 같다고 조율이 확인한 15초로 바꾸고 사진 3장 재실행을 승인했다.

| 사진 입력 종류 | 결과 | 제목 글자 수 | 요점 수 |

| 긴 글 | 성공 | 16 | 5 |

| 글자 없음 | 성공·빈 결과 | 0 | 0 |

- 사진 누적 호출 **6/7회**. 15초 재실행에서 OCR 실패 0건, 글 있는 사진은 핵심 한 줄과 목록 형식, 글자 없는 사진은 텍스트·제목·요약이 빈 결과다.
- 글 있는 사진의 제목은 새 30자 이하 기준을 충족한다. 글자 없는 사진은 기존 빈 결과 규칙을 충족한다.
- **짧은 글 사진 요점 5개는 기존 합격 기준 0–1개를 충족하지 못했다.** 표본을 임의로 재분류하거나 합격 기준·프롬프트를 바꾸지 않았다. 사용자 판단이 필요하다.
- 5초 실행의 세 건은 timeout이었고 15초 실행의 세 건은 성공했다. 시간 제한 차이와 관측 결과를 기록한 것이며, 다른 변수 통제 실험이나 운영 환경의 성공을 입증하지는 않는다.
- 최초 timeout 요청의 비용은 usage 미수신으로 여전히 확인 불가다. 사진 원문·OCR 전문·실제 제목·요약은 저장하거나 이력에 옮기지 않았다.
- 링크 표본 제목 길이는 새 기준으로 모두 통과했으며 [#314 이력](2026-11-09-summary-title-target-length.md)에 기록했다. 링크 의미 판정 자료는 로컬 `.utmp/samples/judge-links.md`에 있다.
- 짧은 글 요점 기준 및 의미 보존·지어낸 요점 여부 사용자 판정 전까지 main 병합·최종 리뷰·PR 초안은 진행하지 않았다. push·PR·원격 CI 없음.
