# iOS 0.2.0 빌드 6 로컬 검증과 배포용 빌드

## 범위와 소스

- 요청: iOS `0.2.0 (6)` 검증과 배포용 빌드 생성. 실제 업로드 제외.
- 소스: `a3972f9118ad1ffa8863d2e2ba64415a064063ee`의 별도 detached worktree.
- [후보 기록](../releases/app-v0.2.0-ios-b6.md)의 SHA를 유지하며 앱 코드·잠금파일은 수정하지 않는다.
- Flutter 3.44.9, Dart 3.12.2, Xcode 27.1 (`27A9275`).
- 기존 로컬 공개 소셜 설정과 `SocialAuth.xcconfig`를 사용한다. 값과 개인 서명 정보는 이 문서에 기록하지 않는다.
- API는 소스의 production 기본 주소를 사용한다. 별도 프리뷰 진입점·대역 서버를 배포 빌드에 넣지 않는다.

## 실행 절차

`frontend/`에서 잠금파일을 유지해 의존성을 준비하고 다음 검사를 실행했다.

```bash
flutter pub get --enforce-lockfile
flutter analyze --no-pub
flutter test --no-pub --concurrency=2 --reporter=expanded
```

시뮬레이터 빌드는 `flutter build ios --simulator --debug`, 아카이브는
`flutter build ipa --release`를 사용한다. 두 명령 모두 `--no-pub -t lib/main.dart
--build-name=0.2.0 --build-number=6`과 문서화된 공개 소셜 Dart define 세 개를 명시한다.
App Store용 export plist는 `method=app-store-connect`, `destination=export`,
`signingStyle=automatic`, `manageAppVersionAndBuildNumber=false`, `uploadSymbols=false`로 지정한다.
실제 업로드 명령과 Organizer 배포는 실행하지 않는다.

## 검증 결과

- 의존성 준비: 잠금파일 유지 성공.
- 정적 분석: `No issues found`.
- 전체 Flutter 테스트: 공간 확보 후 재실행에서 **1,992개 통과**, exit 0, 5분 53초.
  SVG `<filter/>` 미지원 메시지는 출력됐지만 테스트 실패는 없었다.
- 시뮬레이터 빌드: 성공. 본앱과 공유 확장의 실제 plist 모두 `0.2.0 (6)`.
- iOS Simulator: 별도 iPhone 16 Pro, iOS 18.6에서 설치·실행 후 로그인 선택 화면 표시 확인.
- 소셜 설정: 생성된 앱의 Google·카카오 URL scheme과 전달한 공개 Dart define이 일치한다.
- 권한 설명: 사진·카메라·위치 usage description 세 항목 존재 확인.
- 배포용 아카이브·IPA: 생성 성공. 본앱과 공유 확장 모두 실제 `0.2.0 (6)`.
- IPA를 풀어 본앱과 공유 확장 각각 `codesign --verify --deep --strict` 통과.
  배포용 provisioning profile의 앱 식별자와 서명 entitlement가 일치하며 `get-task-allow=false`다.
- 본앱과 확장의 App Group·공유 Keychain, 본앱의 Sign in with Apple entitlement를 확인했다.
  프로파일 만료 시각은 모두 2027-10-12 07:46:14 UTC다.
- 최종 IPA에서도 Google·카카오 URL scheme이 공개 Dart define과 일치한다.
  최종 빌드에는 소셜 공개 설정과 Flutter 기본 define만 있고, 컴파일된 앱에 production API 호스트가 포함된다.
- 본앱 최소 iOS 버전은 17.0, 공유 확장은 15.0이다. 앱 설치에는 본앱의 17.0 제한이 적용된다.

## 검증 한계와 경과

- 이 환경의 Xcode에는 Simulator 화면 앱이 없고 컴퓨터 조작 도구에서도 Simulator를 제공하지 않는다.
  `simctl`로 설치·실행·화면 캡처는 확인했지만 터치·스크롤·사진 선택·실제 공유·로그인 이후 기능은 미검증이다.
- 원본 열람·카테고리 복구·홈·통계의 자동 테스트는 실제 운영 API·OAuth·실기기 시나리오를 대신하지 않는다.
- Android는 이번 iOS 후보 빌드 요청 대상이 아니며 실행하지 않았다. 앱 UI·소스 변경이 없으므로 Figma 비교는 해당 없음이다.
- 초기 시뮬레이터 생성에 설치되지 않은 iOS 27.1을 지정한 시도는 실패했다. 실제 설치된 iOS 18.6으로 생성·부팅했다.
- 시뮬레이터 빌드 중 겹쳐 시작한 아카이브 준비는 중단하고, 시뮬레이터 빌드 완료 후 순차 재실행했다.
- 첫 아카이브와 전체 테스트는 디스크 공간 부족으로 중단됐다. 첫 테스트는 로그상 1,070개까지 진행했으나
  완료 결과가 없으므로 통과한 전체 실행으로 계산하지 않는다. 이번 작업의 시뮬레이터·시뮬레이터 빌드 및
  해당 worktree의 DerivedData 중간 생성물만 정리한 뒤 아카이브와 전체 테스트를 다시 실행했다.
- 아카이브의 개발용 서명과 내보낸 IPA의 배포용 서명을 구분했다. IPA의 배포 서명을 실제로 검사했으며
  아카이브 생성이나 인증서 목록 조회만으로 배포 서명 성공을 추정하지 않았다.
- 빌드 경고: 앱 아이콘이 기본 Flutter placeholder다. 정식 출시 전 디자인이 확정된 앱 아이콘으로
  교체하고 새 소스·빌드 번호의 후보를 준비해야 한다. 이번 고정 소스에서는 변경하지 않았다.
- 개발자 계약 수락, 스토어 업로드·처리, 테스터 배정, 심사·정식 공개, 서버 배포, 태그·푸시는 수행하지 않았다.
