### 17. 2026-10-02 카테고리 조합 검증 통일

<a id="b-99cd4480395cbcb7"></a>

- 생성에서 `미분류 + 일반 카테고리`를 허용하던 불일치를 수정했다. 기존 수정 API의 검증을 공통 함수로 옮겨 직접 링크·공유·스크린샷 저장에도 적용하며 동일한 422 오류 문구를 반환한다.
- ID 중복 제거와 소유권 조회 뒤 조합을 검사하므로 접근 불가 ID의 404가 우선한다. 미분류 단독·복수 일반 분류·빈 목록의 기존 동작을 유지한다. 거절 시 태그·콘텐츠·이벤트·자산·요약 작업을 생성하지 않으며, 수정 거절 시 기존 분류·이벤트와 요약 작업의 `apply_category`를 보존한다.
- 수정 전 서비스 테스트 3건과 실제 PostgreSQL HTTP 저장 경로 5건의 실패를 재현했다. 수정 후 서비스·분류 통합·기존 저장/업로드/YouTube 회귀 테스트 **95개 통과**를 확인했다. 스크린샷은 실제 파일 생성 후 검증 실패에 따른 보상 삭제와 잔여 파일 없음까지 확인했다.
- 전체 `pytest -q`는 **878개 통과**(회귀 사례 21개 추가, DB 테스트 skip 없음)했다. `ruff check app alembic tests`, `python -m compileall -q app alembic tests`, `git diff --check`와 빈 테스트 DB의 `alembic upgrade head`·`alembic check`도 통과했다. 기존 Starlette/httpx 사용 중단 예정 경고 1건은 남아 있다.
- 검증 환경은 Python 3.12.7 및 격리된 PostgreSQL 17.7이다. Docker daemon이 실행되지 않아 로컬 설치 PostgreSQL을 사용했다. 외부 메타데이터·AI·OCR 응답은 대체하고 YouTube worker는 비활성화했다. 메타데이터·OCR 호출 순서는 변경하지 않았다.
- DB 스키마·기존 데이터·프론트엔드는 변경하지 않았다. 원격 CI·PostgreSQL 16·Railway·실제 외부 공급자·실기기 검증은 미실행이다.
