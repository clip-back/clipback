# 이미지 사용량 조회·신규 저장 중단 구현과 검증

2026-10-23, 이슈 #72. 기준 main은 `5671e79`, 운영 제어 기능 커밋은 `cfcdd70`,
클라이언트 안내 커밋은 `060e77b`다. 계정 한도와 원본 캐시 구현을 작업 브랜치에 병합했다.
이 기록은 로컬 합성 자료 검증이며 운영 배포·청구 확인을 의미하지 않는다.

## 구현

- 원본의 계정별 논리 사용량, 로컬·원본 Bucket·백업 Bucket의 물리 보관량,
  익명 전송 관측값을 운영 명령으로 구분했다. 사용자가 삭제한 원본의 논리 용량은 즉시 반환되지만
  물리 사본·누적 관측 전송량은 별도 의미를 유지한다. 미참조·불완전 백업 객체도 보관량에 포함한다.
- 전송은 성공 커밋 원본 쓰기 payload, API가 준비한 원본 응답 payload, 접근 정보 발급 건수다.
  직접 Bucket의 실제 다운로드·프로토콜 오버헤드·백업 전송·실제 청구액은 알 수 없어 `null`이다.
  독립 삭제 기록 저장소의 보관·전송량도 별도 `null`로 표시하므로 세 보관량 항목을 전체 비용으로 합산하지 않는다.
  월 1만 원은 서버·DB·AI 비용과 분리한 설계 목표이며 자동 비용 상한이 아니다.
- DB 전역 상태와 shared/exclusive 트랜잭션 잠금으로 신규 이미지 저장의 중단·재개를 제공한다.
  중단 명령은 이미 허용한 저장의 커밋·롤백을 기다린다. 완료된 공유 재전송을 먼저 확인하고,
  새 요청만 OCR·원본 쓰기 전에 거절한다. 읽기·삭제·링크 저장은 이 정책을 사용하지 않는다.
- Dart·Swift·Java가 `409/image_uploads_paused`를 기존 오류 영역의 한국어 사유로 표시한다.
  새 사용량·결제·오류 레이아웃이나 알림 채널은 추가하지 않는다.
- 마이그레이션 `202610230018`에 전역 상태와 UTC 일별 익명 카운터를 추가했다.
  일반 API에 백업 자격증명을 추가하지 않았으며 운영 보고 명령만 별도 0600 자격 파일을 읽는다.

## 자동 검증

- 초기 재현에서 중단 상태를 저장해도 새 API 요청이 201로 성공했다. 전역 제어 적용 후 409가 되었고,
  거절한 요청이 외부 OCR에 진입하지 않음을 확인했다. Dart도 일반 오류 문구로 실패한 뒤 전용 사유로 통과했다.
- 실제 PostgreSQL 통합 경계에서 본앱·공유 중단, 완료 공유 재전송, 기존 원본 조회·삭제, 재개,
  이미 허용한 저장과 운영 중단의 경합, 동일 키 병렬 재시도 후 원본 중복 방지를 확인했다.
- 합성 77바이트 원본 2개, 로컬 미참조 5바이트, Bucket 미참조 3바이트, 백업 18바이트의 보고값이
  알려진 자료와 일치했다. 삭제 후 논리 사용량만 반환되고 백업·과거 전송 집계가 유지됨을 확인했다.
- 실제 CLI 자식 프로세스와 로컬 HTTP S3 대역에서 중단·재개·보고를 실행했다. 자체 UUID Bucket만
  생성·삭제했으며 로컬 5바이트·원본 3바이트·백업 7바이트가 일치했다. 공개 권한 0644 자격 파일은
  종료 코드 1로 거부했고 출력·stderr에 파일 키·테스트 비밀값·서명 URL이 없음을 확인했다.
- 업로드·삭제·공유 주변 검사 63개가 통과했다. 이후 계정 한도 병합 상태의 한도·운영 제어·CLI·업로드
  검사 34개가 통과했다. Flutter API·인증·실제 저장 위젯 검사 53개도 통과했다.
- 변경된 Dart 정적 분석, Python Ruff, Alembic 메타데이터 비교와 diff 공백 검사를 통과했다.
  전체 통합 검사와 최종 리뷰는 #74에 기록한다.
- 최신 일일 백업 구현 병합 후 관련 백엔드 34개(6.58초), Flutter 53개와 정적 분석(2.2초)을
  재실행해 통과했다. 운영 이미지 `clipback-image-operator72:check`를 PostgreSQL 16 기반으로 실제 빌드하고
  컨테이너에서 `python -m scripts.image_storage_admin --help`가 세 명령을 제공함을 확인했다.
  이는 패키징 검증이며 실제 운영 DB나 청구 서비스에 접속한 결과가 아니다.

`Clipback_Share_API_33` / Android 13(API 33) Emulator에서 수행했다.
