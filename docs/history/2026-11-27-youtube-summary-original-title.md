# 유튜브 요약 실패·건너뜀 때 원래 제목 표시 (#491)

20분을 넘긴 영상은 요약을 건너뛰면서 상세와 목록에 ‘저장한 콘텐츠’로 남았다. 서버는 이제 유튜브 사전 확인에서 이미 받은 `snippet.title`을 실패·건너뜀·재시도 대기 중에 표시한다. 직접 입력한 제목은 보존하고, 재시도에 성공하면 자동 요약 제목을 반영한다. 사전 확인에서 제목을 얻지 못했거나 임대가 만료된 작업은 기존 제목을 유지한다. [서버 동작](../youtube-summary.md)

## 검증

시작 커밋은 `642a062`, 구현 및 최종 검사 커밋은 `06079d7`이다. 실제 공급자 호출 없이 기존 대역으로 확인했다. Gemini 429·400 사례는 구현 전 모두 제목 단언에서 실패했고, 구현 뒤 관련 pytest 11개 파일의 451건이 통과했다. 공개 필드 단언은 사용자 승인에 따라 이 두 상태의 제목만 원문과 일치하는지 검사한다. 그 밖의 공개 필드와 모든 상태의 로그에 작성자 표식이 없는지도 확인했다.

검수에서 명세 지적은 없었다. 120자로 자른 결과가 공백으로 끝날 수 있다는 의견은 반영하지 않았다. 명세는 앞뒤 공백을 제거한 뒤 120자로 자르도록 정했고, 원래 제목 안의 공백이 120번째 글자가 될 수 있다.

| 전체 검사 순서 | 결과와 후속 확인 |
| --- | --- |
| 구현 첫 실행 | 주간 집계의 콘텐츠 삭제 경합 테스트가 10초 대기 뒤 시간 초과했다. Flutter 테스트 프로세스 4개가 SIGTERM으로 종료됐다. 시작 커밋에서 두 실패를 비교했을 때 전체 12개 검사가 통과했다. 구현 커밋에서 주간 집계 테스트와 해당 Flutter 파일 4개를 각각 단독 5회 실행해 25회 모두 통과했다. |
| 구현 두 번째 실행 | 첫 두 증상은 재현되지 않았다. Flutter 4,440건이 통과했다. 롤백 정리 테스트만 실패했고, 정리 후 `non_idle_backends`는 기대 0, 관측 1이었다. 조율은 이를 **시트 131·161 알려진 불안정**으로 분류했다. 기존 실험은 PostgreSQL autovacuum worker가 집계에 포함될 수 있음을 확인했다. 이번 실패 시점의 프로세스 종류는 기록되지 않았다. |
| 구현 최종 실행 | 롤백 정리 테스트 단독 5회 모두 통과한 뒤 코드를 바꾸지 않고 전체 검사를 재실행했다. 백엔드 pytest 3,557건 통과·52건 건너뜀, Flutter 4,440건 통과. 전체 12개 검사 통과. |

최종 로컬 결과와 건너뛴 사유는 다음과 같다.

```text
pytest skip: 51 tests/deployment (RUN_DOCKER_RECOVERY_TESTS=1 and a labelled local image are … 외 6종)
pytest skip: 1 tests/integration (CLIPBACK_IMAGE_TEST_S3_ENDPOINT is required for the local s…)
```

서버 변경으로 앱 화면과 기기 촬영은 범위 밖이었다. 실제 YouTube Data API·Gemini, 운영 서버, Docker 복구 테스트, S3 통합은 이 로컬 검증에서 실행하지 않았다. 배포 뒤에는 사용자가 선택적으로 20분 넘는 공개 영상을 저장해 상세 제목을 확인할 수 있다.
