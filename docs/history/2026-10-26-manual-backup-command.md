## 구현과 검증 경계

- 수동 `manual`과 `daily`는 복구 지점 생성만 하고, `maintain`은 백업 보존 정리만 수행하도록 분리했습니다. 원본 삭제 재처리는 기존 별도 명령을 사용합니다.
- 운영자 설정·DB 연결·저장소를 명시적으로 공급해 API의 AI·로그인 설정 없이 백업할 수 있게 했습니다. API의 기본 설정 검증과 기존 동작은 유지합니다.
- PostgreSQL 18을 운영자 이미지의 기본값으로 사용하며 필요한 버전으로 빌드할 수 있습니다.
- 백업 스냅샷·독립 삭제 기록·물리 원본 보호·완료 manifest 마지막 게시 계약을 유지했습니다.
