폭75→약76.885(좌우각약0.942px 증가)이다. alpha>0 외곽은 아래로약2.815px 나가도 자르지 않는다.
원본의 alpha>128 경계 `(16,28)-(958,1486)`에 균일 배율 `119/1458`을 적용하여
내부 Image83.08779×126.10082·offset(0.75171,-0.28532)로 배치하며 슬롯 Stack은 `Clip.none`이다.
승인된 PNG 바이트·원본 비율·외부81×123 슬롯과 주변 문구·버튼 배치는 유지한다.
원본 파일 가공이나 비균일 확대는 하지 않는다. 전체 외곽의 슬롯 기준 경계는
